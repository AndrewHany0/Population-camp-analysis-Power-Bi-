📊 Refugee Camps Population Analytics Dashboard


📌 Project Overview

This Power BI dashboard analyzes refugee camp population and infrastructure data across multiple countries.

The dashboard provides interactive visualizations that help explore population distribution, gender composition, housing resources, and facility availability at both country and city levels.


🎯 Business Objective

The objective of this project is to provide decision-makers with a clear view of:

Population distribution

Gender composition

Housing capacity

Camp infrastructure

Country-level comparisons

City-level resource allocation
